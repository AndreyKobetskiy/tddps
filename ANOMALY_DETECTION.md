# Метод обнаружения аномалий

В `detect.py` используется пороговый метод. Для каждого показания детектор рассчитывает, насколько оно отклоняется от ожидаемого значения в единицах обычного разброса. Если оценка **строго больше 5**, показание помечается как аномальное.

## Общие метрики каждого объекта

Для каждого станка и момента времени детектор берёт медиану показаний наблюдателей данного объекта. При трёх наблюдателях медиана — центральное значение, при четырёх — среднее двух центральных. Оценка равна абсолютной разнице между показанием и медианой, делённой на `√2 × σ`, где `σ` — стандартное отклонение измерительного шума для этого параметра из генератора.

Например, наблюдатели передали **61,9, 62,0 и 63,4 °C**. Медиана равна **62,0 °C**, а шкала — `√2 × 0,12 ≈ 0,17 °C`. Для третьего показания оценка равна `|63,4 − 62,0| / 0,17 ≈ 8,25`. Детектор отмечает аномалию. Для **62,2 °C** оценка была бы около **1,18**, ниже порога.

## Ток токарного станка

Детектор прогнозирует ток по формуле `I_прогноз = 2,5 + 0,12 × L`, где `L` — медиана показаний нагрузки в процентах. Коэффициенты взяты из модели генератора. Затем считается **остаток** — измеренный ток минус прогноз.

Остаток сравнивается с медианой предыдущих остатков того же наблюдателя за 60 секунд. Шкала разброса равна `max(0,05 А, 1,4826 × MAD)`. MAD — медиана абсолютных расстояний от прошлых остатков до их медианы. Статистика обновляется раз в секунду. Пока накоплено меньше 20 остатков, используются центр 0 и шкала 0,05 А.

Например, при нагрузке **50%** ожидается **8,50 А**. Если измерено **9,00 А**, остаток равен **+0,50 А**. При исторической медиане **+0,01 А** и шкале **0,05 А** оценка равна `|0,50 − 0,01| / 0,05 = 9,8`. Это аномалия. Для **8,56 А** оценка при той же истории равна **1,0**, ниже порога.

## Результат

Детектор сохраняет идентификатор наблюдателя, время, подозрительное поле, оценку и название правила. Разметка используется после обнаружения для расчёта precision и recall. Детектор проверяет три общих поля каждого объекта и дополнительно ток токарного станка.
